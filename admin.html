Before this is used for real

  • Administrator authentication moves to a server-side session with multi-factor authentication
  • Every request re-checks the role; nothing is trusted from the browser
  • Each action writes an audit entry before it takes effect
  • Administrator roles are separated: support, billing, platform and security
  • Access to any private organisation content requires an explicit, logged permission
