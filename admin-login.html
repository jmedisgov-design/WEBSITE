This gate is not security

It runs entirely in the browser. The credential is in assets/js/admin.js, which anyone can read, and clearing it in the console would open the portal. It exists so that the administrator step is visible in the prototype and the portal is not reached by accident from the public site.

Before this goes anywhere real, administrator access must be a server-side session with a role check on every request, an audit entry per action, and multi-factor authentication on the account.

What the portal shows

  • Active users, organisations and subscriptions
  • Revenue by licence category
  • Questions asked, most-used agents and models
  • Model failures, data failures and active simulations
  • API usage against quota, and storage
  • Reports generated and Academy enrolments
  • The administrator audit trail

Administrators see aggregates. Private user content is not exposed to an administrator unless their permissions explicitly allow it.
