Agents know which model to call

An agent is not a persona. It is a registered specification: the questions it accepts, the models it calls, the data it needs, the scenarios it supports and the access level required to use it. Cross-sector questions call several agents at once.

The agents that call everything else

Strategic agents answer questions no single sector can. They assemble workflows across the fiscal framework, several sector models, the appraisal system and the economy-wide model, then reconcile the results.
