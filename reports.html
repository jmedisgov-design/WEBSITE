Product

The output is a document someone can defend

Every EDIS report states the model used, the data used, the scenario, the assumptions, the results, the limitations, the date and the run ID. The analysis and the document that carries it are produced from the same record.

Formats

Nine report formats

Generated from a completed run, in the register and length each audience expects.

2 pages

Executive summary

Top findings, key risks, budget implications and recommended actions for a minister or a board.

4–6 pages

Policy brief

The question, the options, the evidence for each, the trade-offs and the decision required.

20–60 pages

Technical report

Full method, parameters, data tables, sensitivity analysis, diagnostics and annexes.

Per project

Investment appraisal

Economic return, cost profile, readiness, risk and pipeline fit, in the appraisal format.

Per sector

Sector report

Coverage, gaps, costed programme, spatial distribution and the economy-wide effect.

Per country

Country report

Macro-fiscal position, sector diagnostics, investment pipeline and poverty outlook.

Sub-national

District report

Local provision, gaps, projects and the effect of a national scenario at district level.

Per run

Scenario report

Shocks as entered, results, comparison against baseline and against other scenarios.

Per programme

MEL report

Results chains, indicator projections, target gaps and progress against the framework.

Downloads

In the formats institutions actually use

  • PDF — for circulation and the record
  • Word — where the report becomes part of a larger submission
  • Excel — result tables with the parameter sheet attached
  • CSV — for onward analysis
  • Charts — vector, at publication quality
  • Maps — with the layer set and projection recorded

Export rights follow the licence. Public users can download published reports; registered users have limited generation; professional and above generate and export without restriction within their run allowance.

Confidence

What EDIS says when it is not sure

A report is not more useful for hiding its weaknesses. Confidence, limitations and validation status are printed alongside the results, not buried in an appendix.

Confidence

Recorded per run as high, medium-high, medium or indicative, based on data quality, model status and how far the scenario is from the calibration range.

Limitations

What was held fixed, what is modelled at a coarser level than the question implies, and what falls outside the models entirely.

Validation status

Validated, partial, or failed with the reason. A non-converged run can be inspected but is never presented as a result.
